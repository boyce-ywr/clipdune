# ClipDune 设计基线

日期：2026-10-21。状态：首个开发预览，不是正式发行承诺。

## 已确认的用户决定

1. 自用优先，未来可能付费上架 Mac。
2. Windows 只是后续选项，不为它牺牲当前原生体验。
3. 不直接采用 Clipbara 源码；独立实现，只参考产品交互。
4. 工程放在当前工作目录的独立目录，同步到用户 GitHub 私有仓库。
5. 第一优先级来自真实反馈：全屏终端中能可靠唤出，打开就能输入搜索，不额外点输入框。

## 产品约定

工具不应让用户离开当前工作。正常路径是：快捷键唤出 → 输入 → 方向键选取 → 回车 → 回到原位置。

- 展示：一个底部卡片面板，不实现两套主界面；按鼠标所在显示器定位。
- 焦点：展示与输入准备是一项操作，明确获得 key window 和搜索框 first responder；下一轮主循环的补充聚焦绑定当前展示代次，不允许过期回调重新抢焦点。
- 输入：原生 NSSearchField / NSTextView 处理组词。输入法有 marked text 时，不截获快捷粘贴与导航命令。
- 退出：Esc、切换空间或点击其他应用收起。退出不主动激活另一个 Space，也不在未确认焦点的情况下发送粘贴。
- 目标：唤出时记录原应用和可访问性输入元素；粘贴前再次比较。不匹配就只写剪贴板，提示用户手动粘贴。
- 查询：异步检索结果有代次检查，较早的查询不能覆盖较新的查询。
- 滚动：选中项同步不等于滚动复位。面板每次打开和重置查询结果时，在布局完成后明确回到横向起点；“回到最新”按钮复用此行为但保留当前查询条件。

## Module 划分

| Module | Interface | 实现职责 |
| --- | --- | --- |
| HistoryStore | record / search / content / pin / delete / archive | SQLite 事务、索引、去重、限额、版本与备份校验 |
| PasteboardCodec | read / write | 白名单表示、多个条目、敏感标记、保真回填、缩略图 |
| ClipboardMonitor | start / stop / pause / requestAccess | 变化轮询、权限状态、排除来源、采集期间的变化检查 |
| ClipboardPanelController | show / hide / update | 非激活面板、Space 与显示器、键盘焦点、检索与卡片交互 |
| PasteDestination | capture / pasteIfStillFocused | 原目标身份与输入元素验证、按当前键盘布局发送粘贴 |

目前不建立虚构的多平台抽象；Core 不包含 AppKit 窗口代码，但仍使用 Apple CryptoKit。将来 Windows 确立后再验证数据与哈希实现，并增加真实的系统适配实现。

## 内容与生命周期

一次复制由多个有序片段组成；每个片段拥有一组原始类型／数据表示。内容指纹不依赖同一片段内表示的排列，保留多个片段的顺序。

来源应用不参与内容指纹。重复复制更新最近时间和来源、保留收藏状态。历史、收藏与临时粘贴状态分开，不把队列语义混入去重。

数据库记录与 FTS 索引在同一事务中变化。未来版本的数据库拒绝打开，不静默重建。导入先完整校验，再事务合并；清理不删除收藏，预算不足且无法安全清理时回滚新内容。

## 权限与安全约定

- 背景读取和直接粘贴是独立授权，不依赖屏幕录制权限。
- 在提供 accessBehavior 的系统上，不对 Ask / Deny 状态反复后台读取；保留用户主动授权入口。
- 剪贴板内容不调用远端接口；0.2.0 仅增加可选 GitHub 更新请求。不渲染不可信 HTML 预览，不自动执行复制的命令或打开链接。
- 所有诊断只记录状态、类型和验证结果，不记录剪贴板正文。
- 不为测试关闭 Gatekeeper、系统完整性保护、企业终端防护或重置用户权限。

## 发行之前必须补齐

实际终端兼容矩阵、双显示器与不同 Space 设置、长时间运行、权限撤回与恢复、备份升级、沙盒与文件访问、合法签名公证、隐私清单、购买机制，以及品牌和许可审核。

## 0.2.0 交互与更新补充

搜索框失焦后的输入在面板窗口层恢复焦点，再交给原生文字事件管线；不将按键转成字符串自行拼接。双击统一命中条目并执行默认粘贴，Shift 反转纯文本偏好，Option 仅复制。

设置采用独立原生工具栏窗口，核心配置保存到 UserDefaults 并同步到运行中的 Module；GitHub 令牌单独放在 Keychain。权限入口主动打开系统对应页，但不代替用户授权。

更新只消费固定私有仓库的已签名正式 Release，认证限定 GitHub API 固定仓库路径；安装 helper 不提权，使用原子交换与启动确认，失败恢复旧应用。完整设计与验证边界见 `updates.md`。

## 0.3.0 卡片与检索补充

卡片提供常驻鼠标按钮与右键菜单，按被点击条目的稳定 ID 路由，不依赖之前选中项。正文双击与控件点击隔离。应用图标按来源 Bundle ID 在本机查找，内容大小采用类型相关口径。

类型、时间、关键词与收藏条件在数据库查询中取交集。时间边界基于本地自然日，包含起点、不包含终点。名称只作元数据并参与搜索索引，不改变原内容、去重指纹、复制时间或粘贴字节。

保持旧主表列数与 schema 版本，使用附表与兼容载荷扩展类型和名称；删除与索引一致性、旧格式导入、旧写入语句与新名称备份均有隔离测试。详情见 `content-and-search.md`。
