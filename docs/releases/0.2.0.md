# ClipDune 0.2.0

- 搜索框失焦时直接打字，自动聚焦并开始检索；中文组词继续由原生输入法处理。
- 双击卡片直接粘贴；等待原输入焦点恢复，缺少权限时打开辅助功能设置。
- 剪贴板权限按钮自动打开系统对应设置页。
- 新增通用、外观、快捷键、排除、关于与更新设置窗口，设置即时生效并持久保存。
- 支持私有 GitHub Release 更新：钥匙串保存读取令牌、签名与安装包校验、确认安装、重启失败回滚。

首次从 0.1.0 升级需要手动安装这个带更新器的版本。此后可在“设置 → 关于与更新”中检查。

发布包仍需遵循当前 macOS 的签名与安全策略；更新机制不会绕过系统安全检查。

验证边界：这是开发预览。Release 应用包的普通／全屏交互、设置界面、签名校验及隔离安装事务测试通过；真实终端授权后的插入、实际用户应用更新后自动重启仍需继续验收。没有 Developer ID 公证，不把生成 ZIP 等同于正式发行验收。
