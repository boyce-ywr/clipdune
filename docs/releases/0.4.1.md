# ClipDune 0.4.1

- Release 同时提供两种 DMG：`ClipDune-0.4.1-macOS-arm64.dmg` 用于 Apple Silicon，`ClipDune-0.4.1-macOS-x86_64.dmg` 用于 Intel。
- 打开 DMG 后，将 ClipDune 拖入 Applications 即可安装。两种镜像中的主程序和更新辅助程序均为对应的单架构，并在打包后重新签名。
- 在线更新 ZIP 改为 Universal，包含 arm64 与 x86_64 两种架构；沿用原签名公钥、更新入口和清单格式，两类 Mac 共用同一在线更新通道。
- 增加 `SHA256SUMS.txt`，覆盖两个 DMG、Universal ZIP 和签名更新清单。发布前校验镜像挂载、内容、架构和签名，再下载草稿资产复核。
- 保留 0.4.0 的容量设置、格式保真去重与最近使用排序；最低系统要求仍为 macOS 14。

仍为未公证的开发预览版，未提交 Mac App Store。本次在 Apple Silicon 上构建和验证；Intel 包完成交叉编译及静态封装校验，但未经过 Intel 实机运行验收。

当前仅作为草稿：本机复制后的开发签名应用出现 `SIGKILL`，DMG 内应用尚未通过运行验收，不能将静态签名与架构检查替代运行通过。线上更新入口保持 0.4.0。
