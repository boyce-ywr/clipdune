# ClipDune 0.3.0

## 卡片操作更顺手

- 每张卡片都可以直接点击收藏／取消收藏、重命名、预览、复制和粘贴；鼠标悬停显示操作说明。
- 右键或点击“更多”可访问全部操作，删除单独放在菜单底部，减少误触。
- 点卡片按钮会操作当前点击的条目，不依赖之前的选中项；双击按钮不会误触正文的直接粘贴。
- 显示来源应用图标、复制时间和快捷键编号。文本显示字符数，图片显示首选图像表示的数据量，文件显示引用数量。
- 面板跟随当前显示器的可见宽度，左右各保留 16 pt，不再限制到固定的 1,140 pt 宽度。

## 类型、时间与名称检索

- 区分文本、富文本、HTML、图片、链接、文件、颜色、其他八种类型；保留已捕获的原始数据表示。
- 顶部类型与时间筛选可以和关键词、收藏组合使用。时间支持今天、昨天、最近 7 天、最近 30 天及全部时间，可一键清除。
- 每一项都可重命名，历史和收藏共享名称，并支持按名称查找；名称不会替换实际粘贴内容。
- 复制同一内容仍保留名称和收藏，名称也随备份导出／导入。

## 兼容与边界

- 自动为既有历史回填类型和来源信息，保持旧版主表结构与可读取载荷；不迁移或清空用户历史。
- “其他”表示将合法格式名的原始字节保存并回填，不保证任意目标应用都能识别；不会执行这些数据。
- 文件只保存引用，不读文件内容或将引用数据量误标为文件本身大小。
- HTML 以安全的文字摘要展示，不加载脚本或远程资源；RTF 与 HTML 同时存在时按富文本归类。
- 当前仍是开发预览，未作 Developer ID 公证。实际终端授权后的插入和完整旧版到新版自动重启链路需与界面测试分开验收。
