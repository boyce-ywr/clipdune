# ClipDune 0.4.0

- 总存储容量不再固定为 256 MiB：在“设置 → 通用”中选择 64、128、256、512 MiB、1 或 2 GiB，并查看已用容量与收藏占用。
- 降低容量前弹窗确认；超限时优先清理最久未使用的非收藏历史。收藏计入容量但不自动删除，无法容纳收藏时保留原设置和全部内容。
- 修复应用内复制和粘贴后旧条目没有移到最前的问题。成功复制或发出粘贴指令会刷新最近使用时间，原条目、名称、收藏与格式保持不变。
- 同内容、同格式的再次复制继续合并；文字相同但富文本、HTML 等格式不同则分别保留，避免去重丢失粘贴格式。
- 卡片时间、时间筛选、条数／容量／过期清理统一依据最近使用时间；悬停仍能查看独立保留的最近采集时间。
- 兼容旧历史与备份，导入旧备份不会倒退已有条目的最近使用时间。主表 schema、数据路径和更新签名公钥不变。

## 边界说明

- 单项原始内容仍限 16 MiB；完整备份另限 384 MiB，导入最多 20,000 项，不随历史容量扩大。容量统计不包含数据库、索引和 WAL 的实际磁盘开销。
- 不额外监听其他应用中的手动 `⌘V`。自动粘贴失败但内容已成功复制时，仍计为一次使用；发送粘贴指令不等于确认目标应用已插入。
- 本包适用于 Apple Silicon（arm64），最低 macOS 14。仍是未公证的开发预览版，未提交 Mac App Store；真实终端插入与完整升级重启需独立验收。
