# ClipDune 0.4.2

- 仓库改为公开，在线更新不再需要配置 GitHub 访问令牌。“设置 → 关于与更新”移除了令牌配置；自动检查默认按天执行，无需额外授权。
- 修复部分编辑器未向辅助功能暴露输入控件时，直接粘贴被误判为“原输入位置不可用”的问题。
- 菜单栏图标不再显示悬停提示。
- Release 同时提供 `ClipDune-0.4.2-macOS-arm64.dmg`（Apple Silicon）和 `ClipDune-0.4.2-macOS-x86_64.dmg`（Intel）。打开 DMG 后将 ClipDune 拖入 Applications 即可安装。
- 在线更新 ZIP 为 Universal，包含 arm64 与 x86_64；沿用原签名公钥、更新入口和清单格式。`SHA256SUMS.txt` 覆盖两个 DMG、ZIP 和签名更新清单。

## 升级说明

- 0.2.0–0.4.0 已保存令牌的用户仍可直接在线升级到本版本；未保存令牌的用户需手动下载 DMG 安装一次。升级后旧令牌不再使用，可在“钥匙串访问”中删除 `com.github.boyce-ywr.clipdune.updates` 条目。
- 仍为未公证的开发预览版，未提交 Mac App Store；Intel 包完成交叉编译及静态封装校验，未经过 Intel 实机运行验收。最低 macOS 14。
