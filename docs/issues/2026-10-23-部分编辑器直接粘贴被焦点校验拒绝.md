# 部分编辑器直接粘贴被焦点校验拒绝

- 发现日期：2026-10-23。
- 严重程度：P2，部分可手动输入的目标只完成复制，不能自动粘贴。
- 影响实现：0.4.0 与 0.4.1 草稿共用的 `PasteDestination.pasteWhenReady`。
- 修复 commit 可通过 `git log --all --grep='修复未暴露输入控件时的粘贴误判'` 定位。
- 当前状态：代码回归修复，未发布、未替换用户运行中的应用；截图对应编辑器尚未完成授权后的真实插入复测。

## 用户现象与证据边界

用户反馈部分编辑区域手动输入正常、其他剪贴板工具能粘贴，而 ClipDune 显示“原输入位置不可用或已切换”。不是所有目标失败。

旧提示把焦点不可用、目标切换、键盘布局问题甚至未记录到目标应用统一显示，单凭截图不能区分具体失败分支。当前外部诊断进程 `AXIsProcessTrusted()` 为 false；这不代表用户正在运行的 ClipDune 没有权限，不能据此替用户修改权限或断言是权限问题。

## 回归复现

原生产策略中，即使原应用 PID、原窗口都未改变，只要原目标和当前目标均没有返回 `AXFocusedUIElement`，16 次轮询仍全部得到 `waitingForFocus`。延长等待无法让“不提供属性”的应用突然提供属性。

新增隔离测试后，修复前执行 `make test`：

```text
FAIL 同一窗口无辅助功能输入控件仍可粘贴
58 scenarios; 278 assertions; 1 failures
```

这确认了真实生产策略中的一条误判路径，不等同于已复现截图对应页面的所有 AX 返回值；控件被网页重建、真实焦点变化等仍可能造成其他降级。

## 定位过程与根因

对照三种解释：目标不暴露 AX 输入元素、目标重建元素导致身份不等、窗口退场后恢复过慢。

第一种存在确定性缺口：旧代码要求相同 AX 输入元素，或“原元素缺失，但当前元素存在且窗口相同”。若两边都缺失则永远不能发送。与此同时，属性读取把 `noValue`、`attributeUnsupported`、`notImplemented` 与 `cannotComplete`、`apiDisabled` 等错误全部压成 nil，无法区分未提供属性和读取失败。

本机 Apple SDK 的 `AXUIElement.h` 明确分别定义了未提供属性、无值、未实现和通信失败的返回码。正常接收键盘事件与对外暴露辅助功能输入对象不能被当成同一个条件。代码层面的误判已证实；用户具体目标是否只由此触发，仍需现场复测。

## 修复

1. 保留 AX 返回码；仅目标从捕获时就未提供输入元素，且当前 AX 读取没有通信／权限错误，才允许窗口级回退。
2. 捕获原应用及窗口编号，重新检查原应用仍在前台。辅助功能窗口和 WindowServer 窗口证据任何一方明确变化，都不能被另一方“相同”掩盖。
3. 回退需要至少一份肯定的同窗口证据，并持续稳定 100 ms。已知输入元素匹配则等待连续稳定至少 25 ms。证据中断或路径变化重新计时。
4. 若原控件曾经存在而后来读不到，不把它当成“目标本来就不支持”；明确控件变化可以等待恢复，但超时仍拒绝。AX 通信错误和权限失败不走回退。
5. 焦点恢复阶段观察外部鼠标按下和键盘输入，发现新输入立即停止自动粘贴；不记录按键内容。每次 AX 请求设置 50 ms 超时，轮询使用约 600 ms 的单调时钟截止时间。
6. 不读取剪贴板正文、窗口标题、输入框文字或截图；不更改目标内容、点击位置、前台应用、系统安全策略或权限。最终仍通过原来的 `⌘V` 事件发送路径粘贴。
7. 提示分别说明窗口切换、控件切换、新的外部输入、无法确认焦点、键盘布局问题及未捕获原目标，便于下一次反馈准确定位。

## 验证与未验证

- 核心和平台测试覆盖：无 AX 输入元素的同窗口回退；窗口证据缺失／矛盾；明确控件变化；原控件丢失；权限、进程、读取错误；连续稳定等待与重置；真实隔离 AppKit 窗口的 WindowServer 编号变化、浮层拒绝及恢复。
- 修复后 `bash scripts/check.sh`：64 个场景、332 个断言通过，Release 编译通过。
- WindowServer 窗口显隐具有异步提交过程，测试等待可观察窗口编号稳定而非假设 `orderFront`／`orderOut` 同步完成。
- 真实跨应用输入仍未验收：诊断进程没有辅助功能授权，本次不向用户当前文档发任何测试按键。窗口级回退只能验证原窗口，目标不暴露 AX 输入对象时无法证明控件级光标未变化。
- 既有 DMG 复制后运行阻断单独跟踪，不在本次修改中绕过；不覆盖运行中的 `dist/ClipDune.app`。

## 避免再犯

不能把辅助功能属性不存在等同于控件不能输入，也不能把任意读取失败都作为放宽校验的理由。回归必须同时包含兼容路径和不允许粘错目标的反例。不能用合成按键回调、静态策略测试或“已发送”提示代替具体编辑器的真实插入验收。
